# TurnProofs (SaaS Platform)

Welcome! This is the dedicated Next.js (App Router, Tailwind CSS, TypeScript) project for TurnProofs — Turnover verification without the app friction.

## 🚀 Platform & System Info
1. **Database & Storage**: Postgres tables and storage bucket (`airbnb-proofs`) in Supabase.
2. **Environment Variables**: Managed via `.env.local`.
3. **Product Branding**: TurnProofs (`https://turnproofs.com`).
